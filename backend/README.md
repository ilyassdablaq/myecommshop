# DAB ZONE — Backend

Commerce backend for the DAB ZONE online shop: products, orders, customers, carts, and the admin dashboard.

## Getting started

```shell
yarn
cp .env.template .env
yarn dev
```

The admin dashboard runs at http://localhost:9000/app, the store API at http://localhost:9000.
